# 蜕变

TouchDesigner 几何、粒子与实时声音响应。

## 项目目标

以蝴蝶形骨骸模型为视觉核心，将三维几何重构为不断生成、扰动与回流的粒子。声音经分析、放大和平滑后，驱动粒子湍动与模型缩放；液态背景、反馈与辉光共同建立有机的视听关系，让形态随声音强弱不断蜕变。

## 我的贡献

模型处理、节点编程、声音映射与视觉合成

完成阶段：几何建模、粒子生成、声音响应与实时输出

现有产出：完整节点分析、五阶段演进、实时视听影像与声音交互

## 实时生成与制作流程

### 1. 几何与概念

整理蝴蝶几何、骨骼表面与演进阶段，建立连续蜕变的视听概念。

### 2. 节点与实时生成

TouchDesigner 将几何、粒子反馈、声音频段与视觉合成连接，按实时输入改变形态。

### 3. 人工调试

调整响应幅度、粒子密度、层次与阶段衔接，整理节点网络和发展过程。

### 4. 可体验成果

保留完整案例、节点网络图、发展序列、反应序列、影片与网页声音交互代码。此项目的核心证据是实时视听生成。
